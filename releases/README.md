# easy-qfnu skill releases

This skill ships a standard-library Python CLI. GitHub Releases record skill tags; they do not attach platform binaries.

版本标签使用 `vYYYY.MM.DD.HH` 日期时间格式，例如 `v2026.08.30.14`。本地版本来自 skill 目录的 `VERSION` 文件。使用前按 `SKILL.md` 更新到最新 Tag，然后从 skill 目录运行 `scripts/easy-qfnu`。启动器不会自动下载或执行远程文件。
